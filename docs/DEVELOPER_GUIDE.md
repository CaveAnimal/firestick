# Firestick Developer Guide

## Project Structure
- `src/main/java/com/codetalker/firestick/` - Backend source
- `src/test/java/com/codetalker/firestick/` - Tests
- `docs/` - Documentation

## Development Setup
- Java 21+, Maven 3.8+, Node.js 18+
- Run `mvn clean package` to build
- Use `mvn test` for running tests

## Contribution Guidelines
- Fork the repo, create a feature branch, submit a pull request
- Write tests for new features
- Follow code style and documentation standards
